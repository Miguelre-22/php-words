# PHP Words

Aplicación web estática que muestra las palabras reservadas de PHP en tarjetas interactivas, con buscador, filtro por categoría y selector de idioma.

## Cómo ejecutar

Abrir index.html en el navegador (doble clic).

Requiere un navegador moderno.
